# 🚦 Road Accidents Analysis Dashboard | Power BI

## 📌 Project Overview

This project presents an interactive Power BI dashboard for analyzing road accidents and casualties. It provides a visual overview of casualty trends, road types, lighting conditions, vehicle categories, and geographical distribution.

## 🎯 Project Objectives

- Analyze year-wise casualty trends.
- Understand casualty distribution by road type.
- Compare urban and rural casualties.
- Analyze casualties under different lighting conditions.
- Examine casualties across vehicle categories.
- Explore the geographical distribution of casualties.
